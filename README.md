# こんだてノート

毎日の昼・夜の献立を決めて、材料・分量・作り方を見て、作った料理を写真で記録するスマホ用Webアプリ。

- 内蔵レシピ（1人分、オーブン・トースターなし、コンロ1口で作れる手順）
- ジャンル・ランダム・1週間分で献立を決めて、カレンダーに記録
- 人数に合わせた分量計算、買い物リスト、自分のレシピ
- 残り材料から相談（内蔵レシピ＋ Google Gemini 無料枠。キーは利用者が自分のスマホに入れる）
- データはすべてスマホのブラウザの中に保存。書き出し・読み込みで機種変更にも対応
- 一度開けばオフラインでも動く（PWA）

## 使い方
スマホのブラウザで公開URLを開き、「ホーム画面に追加」してから使う（iPhoneはとくに、追加しないとデータが消えることがある）。

## 開発
素の HTML / CSS / JavaScript（ESモジュール）。ビルドは不要。

```
npm install        # 画面テスト用の Playwright（アプリ本体には入らない）
npm test           # 単体テスト（node:test）
npm run test:e2e   # 画面テスト（スマホ幅、PCの Edge を使う）
```

仕様は docs/SPEC.md、設計は docs/PLAN.md、進み具合は docs/PROJECT_STATUS.md、復旧手順は RECOVERY.md。
