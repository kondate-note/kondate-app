# 内蔵レシピ チェックリスト

自動テスト（`npm test` の tests/unit/recipes.test.js）で確認していること:
必須項目、ジャンルごとの品数、id・料理名の重なり、分量の形、オーブン・トースター・グリルという言葉がないこと、手順に出てくる道具（レンジ・フライパン・鍋）が道具欄にあること。

自動では判定できないので、人の目で確認すること:

1. **コンロ1口**: 火を使う工程が同時に2つ重ならない（例: 鍋でゆでながらフライパンで炒める、はNG）。レンジや炊飯器との同時進行はOK
2. **ごはん**: 炊飯器で炊いてあるもの、として書いている
3. **分量**: 1人分としておかしくない
4. **手順**: 初めての人でも分かる（火加減・時間が書いてある）
