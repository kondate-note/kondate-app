# 献立アプリ 仕様書（SPEC）

アプリ名（仮）: こんだてノート
作成日: 2026-11-02

## 1. 目的
毎日の昼・夜の献立を考える手間をなくし、自炊を続けやすくする。
材料・分量・作り方をアプリ内で見られて、作った料理を写真つきで記録できる。

## 2. 利用環境
- スマホのブラウザで使う（PCのブラウザでも見られる）
- 置き場所: GitHub Pages（無料）。URLにはGitHubユーザー名が入るため、本名が入らないことを公開前に確認する
- データはすべて利用者のスマホ（ブラウザ）の中に保存。サーバーには送らない（AI相談を除く）

## 3. 台所の条件（レシピ作成の前提）
- 使える: フライパン、鍋、電子レンジ、炊飯器
- 使えない: オーブン、トースター
- コンロは1口 → 同時に2つ火を使わない手順にする

## 4. 機能

### 4-1. 内蔵レシピ（約100品）
- 1人分の材料・分量・作り方、調理時間、難易度
- ジャンル: パスタ15 / 丼もの15 / 定食（肉）15 / 定食（魚）10 / 麺類12 / カレー・洋食10 / 中華10 / 汁物・鍋8 / 副菜5
- 人数ボタンで分量を自動計算（基本は1人分）

### 4-2. 献立を決める
- ジャンルから選ぶ（気分で選択）
- ランダム（完全ランダム）
- 1日分（昼・夜）を決める／1週間分まとめて決める、の両方
- 決めた献立はカレンダーに「予定」として入る

### 4-3. 検索
- 料理名・材料名でレシピを検索

### 4-4. 残り材料から相談
- まず内蔵レシピから、入力した材料で作れるものを表示（オフラインでも動く）
- 「AIにも聞く」ボタンで Google Gemini API（無料枠）に相談
- APIキーは利用者が設定画面で入力し、スマホの中だけに保存（コードには含めない）

### 4-5. カレンダー（記録）
- 日付を押すと、その日の昼・夜の料理（予定／作った）と写真を表示
- 「作った！」ボタンで写真を撮影・選択して記録
- 写真は圧縮してブラウザ内（IndexedDB）に保存

### 4-6. 買い物リスト
- 献立の材料をリストに追加（同じ材料はまとめる）
- 買ったものにチェック、手動で追加・削除もできる

### 4-7. 自分のレシピ追加・編集
- 材料・分量・作り方・ジャンル・調理時間を登録、編集、削除
- 自分のレシピも献立・検索・ランダムの対象に含める

### 4-8. データの書き出し・読み込み
- レシピ・献立・記録・写真・買い物リストを1つのファイルに書き出し
- そのファイルを読み込んで復元（機種変更に対応）

## 5. 今回は入れない機能（あとから追加可）
- お気に入り⭐
- 苦手な食材の登録・除外
- 楽天レシピなど外部サイトからのレシピ取得（クックパッドは規約上、自動取得不可）

## 6. 見た目
- シンプル・すっきり（白ベース、余計な飾りなし）
- ボタンは大きく、文字はくっきり（キッチンで使いやすく）

## 7. 失敗したときの動き
- AI: キー未設定 → 設定画面へ案内 / 回数上限・通信失敗 → 「今は使えません」と表示し、内蔵レシピの結果は表示したまま
- 写真: 保存容量が足りない → エラーを表示し、書き出しをすすめる
- 読み込み: 形式が違うファイル → 読み込まず、元のデータはそのまま残す
- 入力が空のまま保存 → 保存せず、足りない項目を表示

## 8. セキュリティ・コスト
- 費用は無料のみ（GitHub Pages、Gemini API無料枠。Geminiはクレジットカードを登録しないため課金されない）
- Gemini無料枠では送った内容がGoogleの製品改善に使われることがある。送るのは材料名と質問文のみ
- パスワード・個人情報は扱わない

## 9. 完成条件
- スマホで開いて、上記4-1〜4-8がすべて動く
- 写真つきで記録し、カレンダーで見返せる
- 書き出したファイルから別のブラウザで復元できる
